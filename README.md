# OCR + TTS

Приложение для захвата области экрана, распознавания текста через PaddleOCR-VL (LM Studio) и озвучивания через Silero TTS.

## Возможности

- Захват выделенной области экрана (рамка с изменяемым размером).
- OCR через локальный сервер LM Studio.
- Синтез речи через Silero TTS.
- Пресеты: геометрия рамки, голос, скорость, горячие клавиши.
- Сессии: скриншоты, текст, аудио сохраняются на диск.

## Требования

- Python 3.10+
- Windows
- LM Studio с моделью `paddleocr-vl-1.6-q8_0` на `http://127.0.0.1:1234`
